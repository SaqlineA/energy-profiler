CSV format and missing data

Required: timestamp,total_watts. Optional measured watts: lamp,refrigerator,microwave. Timestamps need a timezone (e.g. 2026-01-01T00:00:00Z). Blank watts mean unknown, not off. Use one household per file; 5 MB / 50,000 rows maximum. Replay runs one row per wall-clock second, but energy and chart time use original timestamps. Models must match the recording's sample interval.
